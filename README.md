# بوت تليجرام الذكي لتلخيص القنوات والمحتوى (Telegram Summary Bot)

بوت تليجرام متطور مدعوم بنماذج الذكاء الاصطناعي **Google Gemini** لتلخيص محتوى قنوات التليجرام العامة لآخر يومين (48 ساعة)، بالإضافة إلى تلخيص النصوص الطويلة والرسائل المُعاد توجيهها (Forwarded Messages).

---

## 🌟 المميزات

1. **تلخيص قنوات التليجرام لآخر 48 ساعة**:
   - إرسال معرف القناة أو رابطها (مثل `@alarabiya` أو `https://t.me/saudioffers0`).
   - جلب وتصفية المنشورات المنشورة في آخر يومين تلقائياً.
   - تصنيف الملخص إلى (عناوين عاجلة، تفاصيل مقسمة حسب المواضيع، وخلاصة ختامية).
2. **تلخيص الرسائل المحولة (Forwarded)**:
   - تحويل أي رسالة من أي محادثة أو قناة خاصة لتلخيصها فوراً.
3. **تلخيص النصوص والمقالات**:
   - إرسال أي نص طويل للحصول على أهم النقاط والأفكار الرئيسية.
4. **نظام التبديل التلقائي الذكي (Multi-Model Fallback)**:
   - التبديل التلقائي بين النماذج (`gemini-3.6-flash`, `gemini-3-flash-preview`, `gemini-3.5-flash`) لتفادي أي ضغط على الخوادم (503/429).
5. **مؤشرات تفاعلية**:
   - إظهار حالة المعالجة ومؤشر "يكتب..." (Typing...) للمستخدم باستمرار.

---

## 🚀 التشغيل المحلي (Local Setup)

1. استنساخ المستودع:
   ```bash
   git clone https://github.com/moathalonayq/bot-telegram-summary.git
   cd bot-telegram-summary
   ```

2. تثبيت الحزم:
   ```bash
   npm install
   ```

3. إعداد متغيرات البيئة:
   أنشئ ملف `.env` وضع فيه:
   ```env
   TELEGRAM_BOT_TOKEN=your_token
   GEMINI_API_KEY=your_key
   ```

4. تشغيل البوت:
   ```bash
   npm start
   ```
